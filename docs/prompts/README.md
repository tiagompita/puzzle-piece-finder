# Prompts por ronda

Um ficheiro por ronda de trabalho, `AAAA-MM-DD-tema.md`, para uma sessão nova perceber o que foi pedido e porquê sem o chat.

Formato:

1. **Porquê** — o problema ou feedback que deu origem à ronda (2–5 linhas).
2. **Decisões** — o que ficou decidido (inclui o que foi recusado ou adiado, com números).
3. **Prompt verbatim** — o pedido tal como foi feito, sem reescrever (quando só há reconstrução, diz-se).
4. **Resultado** — o que foi feito, com commits, e o que ficou por fazer.

No fim de cada ronda: preencher «Resultado» e dizer em `docs/HANDOFF.md` que o ficheiro está fechado.
